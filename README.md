# Titanic-Survive-Rate
----------------------------------------------------------------------------------------------------
----------------------------------------------------------------------------------------------------
A program where it predicts whether passenger survived or no based on features customized by the user 
by the naive bayes algorithim

# Features used 

For training the model what's used is 3 variables, ```Gender, Age, Pclass```
For testing the model whats used is 1 variable ```Survival```

# Tools used 

```Python``` and ```Sklearn```

# NOTICE

For gender: 0 is Female and 1 is Male
For Pclass: 1 is First class, 2 is Second class 3 is Third class
